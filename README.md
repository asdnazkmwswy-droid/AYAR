# AYAR | عيار

منصة SaaS لإدارة محلات الذهب والصاغة، بواجهة عربية RTL وتصميم أبيض ولمسات شامبين ذهبية.

## التطبيقات
- `apps/web`: لوحة التاجر وواجهة إدارة المنصة (React + TypeScript + Vite).
- `apps/worker`: واجهة API على Cloudflare Workers (Hono).
- `packages/shared`: أنواع ومخططات مشتركة.
- `migrations`: مخططات قاعدة بيانات D1.
- `docs`: قرارات التصميم والهندسة.

## متطلبات التطوير
- Node.js 22+
- pnpm 9+

## التشغيل المحلي
```bash
pnpm install
pnpm dev
```

> الحالة: تأسيس أولي. لا تستخدم بيانات حقيقية أو أسراراً في هذا المستودع العام. لم يتم إعداد أو نشر موارد Cloudflare بعد.
